# 围棋在线 (Weiqi Online)

一个极简轻量、即开即下、随时随地与好友联机下围棋的 Web 应用程序。支持手机与电脑跨端自适应对弈。

---

## ✨ 核心特性

### 1. ⚔️ 正规对战模式（还原图一）
- **棋盘规格**：9×9 路、13×13 路、19×19 路自由切换。
- **开局设置**：
  - 执黑 / 随机 / 执白座位分配。
  - 让子设置：0 至 9 子（自动落于标准星位）。
  - 贴目设置：默认 6.5 目，支持自由微调。
  - 时间控制：无时间限制、1分+10秒、1分+20秒、15分+20秒、自定义加秒制。
- **好友联机**：一键复制邀请链接，好友在手机浏览器或电脑浏览器打开链接即可直接入座对弈。
- **正规围棋规则引擎**：
  - 严格连通块（Group）气数（Liberties）计算与实时吃子提子。
  - 自杀禁着点判定（无气不可下子，但能提吃对方时除外）。
  - 打劫规则（单劫禁全同，禁止立即回提）。
- **终局点目判断胜负**：
  - 双方连续停着或主动点目进入终局阶段。
  - 自动泛洪搜索黑白领地（数目法与数子法双重支持）。
  - 支持在棋盘上直接点击标记死子（死子自动显带 ✕ 且地域划归对方），实时重新计算并裁定胜负。

### 2. 🎓 教学摆棋模式（还原图二蓝色虚线框）
- **摆棋模式切换**：
  - `● 只下黑子`：方便连续摆放黑子阵型或黑先做活题。
  - `○ 只下白子`：方便连续摆放白子死活题或白棋杀气。
  - `◑ 正常交替`：恢复黑白轮流落子。
- **实时控制按钮组**：
  - `[ 停着 ]`：放弃本手。
  - `[ 撤销 ]`：悔棋，退回上一手。
  - `[ 重做 ]`：前进恢复被撤销的一手。
  - `[ 重新开始 ]`：清空盘面，重置为新局。
- **历史步数回溯与分支尝试**：
  - 步数导航（`|<`, `<`, `第 N 手`, `>`, `>|`），师生可随时跳回到任意手，尝试不同的下法变化。
- **双端毫秒级实时同步**：
  - 老师或学生在任意端摆棋、切换颜色、悔棋，另一端立刻无感同步更新。
- **辅助功能**：
  - `[ 🔢 显示手数 ]`：在棋子上显示 1, 2, 3... 步数编号。
  - `[ 📊 试算点目 ]`：教学中随时评估当前盘面目数优劣。

### 3. 🎨 高质感视听体验
- **高逼真木质棋盘**：天然暖木纹理底色，标准星位与清晰坐标（A-T排除I字母，1-19数字）。
- **3D 光影棋子**：拟真黑曜石微光与温润白玉质感，伴随落子下沉立体投影。
- **真实敲子音效**：采用 Web Audio API 合成真实实木棋盘敲击回响与提子音效，零依赖零卡顿。

## 🚀 启动与使用指南

### 1. 启动服务
确保已安装 Node.js（推荐 Node 18+），在项目目录下执行：

```bash
# 启动本地服务器
npm start
```
服务默认运行在：`http://localhost:3000`

### 2. 与好友联机对弈
1. 在浏览器打开 `http://localhost:3000`。
2. 点击弹窗或顶部右上角的 **“🔗 邀请好友”** 按钮，链接自动复制到剪贴板。
3. 将链接发送给朋友（例如微信、QQ 或浏览器直接打开）。
4. 朋友进入链接后将自动入座为白方（或对局另一方），即可立刻开始下棋！

### 3. 局域网/手机对战
如果朋友在同一 Wi-Fi 或局域网内，可将链接中的 `localhost` 替换为本机内网 IP（例如 `http://192.168.1.100:3000/?room=ABC123`），朋友即可在手机浏览器上随时随地落子！
